## Brand & Style

This design system blends institutional wealth management authority with high-velocity urban proptech utility. Tailored specifically for Singapore’s discerning home buyers, institutional real estate analysts, and private wealth managers, the aesthetic conveys institutional rigor, transparency, and hyper-local precision. 

The aesthetic is Modern Financial Intelligence:
- **Clean Architectural Precision:** Uncluttered layouts with crisp boundaries, tabular figures, and balanced density suited for high-stakes financial evaluation.
- **Micro-Informational Trust:** Distinct, high-legibility attributions (URA, HDB, SLA, OneMap) to signal statutory authority and algorithmic auditability.
- **Calm, Focused Visual Cadence:** Minimal ornamental noise. Depth is achieved through precise tonal contrast, subtle structural borders, and purposeful accent shifts rather than decorative shadows.

## Colors

The palette balances institutional stability with tactical data accents:

- **Primary (`#14283F` - Straits Navy):** Conveys governance and banking pedigree. Anchors view headers, primary action buttons, master labels, and active navigation nodes.
- **Secondary (`#087F8C` - Marina Teal):** Active analytical highlight. Utilized for data visualization series, valuation trends, active filter states, and interactive charts.
- **Tertiary / Success (`#16845B` - Garden City Green):** Represents positive capital gains, rental yields, healthy loan-to-value ratios, and statutory verified transactions.
- **Warning / Attention (`#D99022` - Straits Amber):** Marks unverified asking prices, lease decay thresholds (<60 years balance), en-bloc probability alerts, and pending caveats.
- **Neutral Background (`#F7F9FC` - Clean Alabaster):** A high-performance off-white canvas that softens screen glare under humid tropical outdoor lighting while maintaining superior contrast against layered white card surfaces (`#FFFFFF`).
- **Surface Line / Dividers (`#E2E8F0`):** Soft architectural borders preserving visual compartmentalization without cluttering dense property data tables.

## Typography

The typography leverages Inter exclusively for its exceptional legibility in dense analytical contexts. Tabular figures (`tnum`) and slashed zeros must be enabled globally across all currency valuations (SGD), price per square foot (PSF), floor areas, and percentage rates.

- **Data Density:** Large metric values pair directly with `label-sm` descriptors stacked below or above to save vertical real estate on mobile devices.
- **Hierarchy:** Property titles use `title-md` with `lineHeight: 24px` to accommodate long Singapore development names (e.g., *The Tre Ver*, *Guoco Midtown Modern*).
- **Attributions & Badges:** `label-sm` utilizes uppercase tracking (`letter-spacing: 0.04em`) to optimize scanning speed for legal and governmental data sources.

## Layout & Spacing

A mobile-first 4-column layout fluidly expands into an 8-column layout for tablets and a 12-column layout for widescreen investment workstations:

- **Mobile Viewport (360px – 599px):** 4 columns, `margin: 1rem (16px)`, `gutter: 0.75rem (12px)`. Stacked cards and horizontal swipeable metrics maximize thumb-zone efficiency.
- **Tablet Viewport (600px – 1023px):** 8 columns, `margin: 1.5rem (24px)`, `gutter: 1rem (16px)`. Splits master search filters and map view beside the analytical feed.
- **Desktop Viewport (1024px+):** 12 columns, `margin: 2rem (32px)`, `gutter: 1.5rem (24px)`. Displays simultaneous deep-dive financial breakdowns, historical caveated trends, and geospatial layers.
- **Bottom Navigation Clearance:** Mobile screens implement a constant persistent clearance of `calc(64px + env(safe-area-inset-bottom))` to prevent visual overlap with action bars and financial floating action triggers.

## Elevation & Depth

Visual hierarchy uses **tonal layering with ambient micro-shadows** to preserve crisp visual precision:

- **Base Canvas:** `#F7F9FC` serves as the ground plane.
- **Card Tier 1 (Resting Cards):** Pure White `#FFFFFF` backed by a 1px border of `#E2E8F0` and an ultra-diffused shadow: `box-shadow: 0 1px 3px rgba(20, 40, 63, 0.04), 0 4px 8px rgba(20, 40, 63, 0.02)`.
- **Card Tier 2 (Interactive Hover / Active Focus):** Lifted with `box-shadow: 0 4px 12px rgba(20, 40, 63, 0.08), 0 1px 2px rgba(20, 40, 63, 0.04)` and border shifted to `#087F8C/40`.
- **Floating Modals & Sheets:** Mobile bottom sheets for filters and unit comparables use `#FFFFFF` with `box-shadow: 0 -8px 24px rgba(20, 40, 63, 0.12)`.
- **Data Source Chips & Pills:** Strictly 0 elevation. Flat, micro-bordered elements that live flush on top of white cards to eliminate visual competition with primary property metrics.

## Shapes

The roundedness level is set to `2` (0.5rem / 8px baseline):
- **Property & Financial Cards:** Specifically calibrated to **14px – 16px** (`rounded-xl` token) for outer containers, creating an ergonomic, premium card feel on mobile screens.
- **Input Fields & Search Bars:** 10px – 12px for modern tap targets.
- **Badges, Data Tags & Source Attribution Pills:** Full continuous pill shapes (`border-radius: 9999px`) to immediately distinguish categorical indicators from square analytical data tables.
- **Interactive Buttons:** 10px rounded corners providing a modern, tactile finish that aligns with enterprise fintech standards.

## Components

### 1. Data Attribution Badges & Status Pills
- **URA / HDB / OneMap Statutory Tags:** Monospaced-leaning visual profile. White background, 1px solid `#CBD5E1`, text color `#14283F`, height 22px, padding horizontal 8px, `border-radius: 9999px`. A tiny 4px dot prefix indicates verification status (green for real-time URA caveat feed).
- **Pricing Status Indicators:**
  - *URA/HDB Completed Transaction:* Fill `#16845B/10`, Text `#16845B`, Border `1px solid #16845B/30`.
  - *Asking Price:* Fill `#D99022/10`, Text `#D99022`, Border `1px solid #D99022/30`.
  - *Algorithmic Valuation (X-Value):* Fill `#087F8C/10`, Text `#087F8C`, Border `1px solid #087F8C/30`.

### 2. High-Density Property & Analytics Cards
- **Architecture:** White surface, 15px border radius, 12px internal padding.
- **Header:** Property project name (`title-md`) flanked right by District (e.g., `D09`, `D15`) and Tenureship (e.g., `Freehold`, `99-yr`).
- **Body Grid:** Two-column matrix displaying Metric Key (`label-sm`, `#64748B`) over Tabular Value (`data-metric`, `#14283F`). Example: "Price: $2,420,000" and "PSF: $2,156 psf".
- **Footer:** Inline row featuring the statutory data tag (`URA Caveat`), transaction date, and an interactive micro-sparkline of the 5-year district trend.

### 3. Filter Chips & Quick Selectors
- **States:**
  - *Resting:* `#FFFFFF`, border `1px solid #E2E8F0`, text `#14283F`.
  - *Active:* Solid background `#14283F`, text `#FFFFFF`, border `1px solid #14283F`.
  - *With Count:* Displays a circular pill `#087F8C` with white tabular count (e.g., "CCR (2)").

### 4. Interactive Charts & Micro-Sparklines
- Background uses subtle horizontal guide rules (`#E2E8F0`).
- Historical transactions mapped as filled `#16845B` scatter points.
- Polynomial automated trendline displayed in `#087F8C` (2px solid stroke).
- Asking spread range displayed as an amber shaded region (`#D99022/10`).

### 5. Mobile Bottom Navigation Bar
- **Dimensions:** Fixed 64px height + bottom safe area.
- **Surface:** Glass-like `#FFFFFF/95` with `backdrop-filter: blur(12px)` and 1px top border `#E2E8F0`.
- **Action Slots:** 4 primary destinations (Explore, Caveats, Yield Analytics, Watchlist). Active state displays `#087F8C` with a 3px rounded indicator dot underneath.

### 6. Search & Geospatial Command Input
- Deep Navy search bar `#FFFFFF` with 1.5px `#CBD5E1` border (focus shifts to `#087F8C`).
- Left icon includes integrated Singapore MRT/Road selector icon.
- Right accessory houses quick filter modal toggle with active filter badges.
